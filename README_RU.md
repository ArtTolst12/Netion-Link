# Netion Link

Раздача VPN и прокси-соединения между устройствами без Root-прав.

---

## О проекте

Обычно при включении точки доступа (Wi-Fi Hotspot) Android направляет подключенные устройства в интернет напрямую через мобильную сеть, в обход активного VPN на раздающем телефоне.

Netion Link решает эту проблему:
1. **На раздающем устройстве (Сервер):** запускает локальный HTTP и SOCKS5 прокси-сервер, направляющий весь трафик через активный VPN раздающего смартфона.
2. **На принимающем устройстве (Клиент):** с помощью встроенного TUN VPN-клиента перехватывает весь системный трафик и перенаправляет его на раздающее устройство без необходимости сложной ручной настройки сети.

---

## Возможности

- **Раздача через любые интерфейсы:** точка доступа Wi-Fi (Hotspot), общая локальная сеть Wi-Fi или USB-модем.
- **Два режима прокси:**
  - **HTTP CONNECT** — для веб-серфинга, сайтов и социальных сетей.
  - **SOCKS5** — для онлайн-игр, звонков, мессенджеров (Telegram) и программ с поддержкой прокси.
- **Встроенный VPN-клиент:** подключение любого Android-устройства в один клик без Root-прав.
- **Подключение по QR-коду:** генерация QR-кода на сервере и мгновенное сканирование камерой на клиенте.
- **Автоподбор портов:** если стандартные порты (8080 или 1080) заняты другим приложением, Netion Link автоматически предложит свободные.
- **Мониторинг трафика:** отображение объёма полученных/переданных данных и пиковой скорости в реальном времени.
- **Журнал диагностики:** подробный лог сетевых событий для быстрого выявления неполадок.
- **Мультиязычность:** полная локализация на 10 языков (Русский, English, Deutsch, Français, Español, Português, Polski, 中文, 日本語, 한국어) с автоопределением языка системы.
- **Фоновая стабильность:** удержание сетевого соединения при выключенном и заблокированном экране.

## Установка

1. Перейдите в раздел [Releases](https://github.com/ArtTolst/Netion-Link/releases).
2. Скачайте актуальный релизный APK-файл (`Netion_Link_V2.2.1.apk`).
3. Установите APK на Android-устройство (при необходимости разрешите установку из неизвестных источников в настройках безопасности).

## Инструкция по использованию

### Вариант 1. Раздача с Android на Android
1. **На раздающем телефоне:**
   - Включите интернет и ваш основной VPN.
   - Включите Точку доступа Wi-Fi (Hotspot).
   - В Netion Link на вкладке «Сервер» нажмите «Запустить раздачу».
   - Нажмите «QR-код для подключения».
2. **На принимающем телефоне:**
   - Подключитесь к Wi-Fi сети раздающего телефона.
   - В Netion Link на вкладке «Клиент» нажмите «Сканировать QR-код» и наведите камеру на экран раздатчика.
   - Нажмите «Подключиться к VPN» и подтвердите системный запрос Android.

### Вариант 2. Подключение с ПК (Windows / macOS / Linux)
1. Подключите компьютер к Wi-Fi точке доступа телефона.
2. Откройте системные настройки прокси на ПК:
   - В Windows: Параметры -> Сеть и Интернет -> Прокси-сервер -> Настройка прокси вручную.
3. Введите IP-адрес телефона (отображается на вкладке «Сервер», например `192.168.43.1`) и порт `8080` (HTTP) или `1080` (SOCKS5).

## Сборка из исходников

Требования:
- Android Studio (Ladybug или новее)
- JDK 17 или JDK 21
- Android SDK (API 34 / 35, минимальная версия Android 7.0 — API 24)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ArtTolst/Netion-Link.git
   ```
2. Откройте папку проекта в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Соберите проект через меню:
   **Build -> Generate Signed Bundle / APK...** (или через терминал `./gradlew assembleRelease`).

## Безопасность и приватность

- Netion Link не содержит сторонних трекеров, рекламы и не собирает пользовательские данные.
- Приложение работает полностью автономно внутри локальной сети.
- Трафик передаётся исключительно между вашими устройствами и используемым вами вышестоящим VPN/провайдером.
