# Netion Link

Netion Link --- Android-приложение для работы с сетевыми
прокси-подключениями.

## Возможности

-   Подключение через HTTP-прокси.
-   Подключение через SOCKS5-прокси.
-   Работа с сетевым трафиком через VPN/TUN-механизм Android.
-   Отображение статистики сетевого трафика.

> Доступные функции и поддерживаемые параметры зависят от версии
> приложения.

## Установка

1.  Откройте раздел
    [Releases](https://github.com/ArtTolst/Netion-Link/releases).
2.  Скачайте APK-файл нужной версии.
3.  Установите APK на Android-устройство. Если Android запросит
    разрешение на установку из этого источника, разрешите его только для
    источника, которому доверяете.

Если релизов пока нет, APK ещё не опубликован в разделе Releases.

## Сборка из исходников

1.  Скачайте или клонируйте этот репозиторий.
2.  Откройте проект в Android Studio.
3.  Дождитесь завершения синхронизации Gradle.
4.  Соберите приложение через меню **Build → Build Bundle(s) / APK(s) →
    Build APK(s)**.

Для успешной сборки может потребоваться совместимая версия Android
Studio, JDK и Android SDK, соответствующая настройкам проекта.

## Безопасность

Используйте только доверенные прокси-серверы. Владелец прокси
потенциально может видеть метаданные соединений и незашифрованный
трафик. Само использование прокси не заменяет HTTPS и другие меры
защиты.

Перед использованием приложения проверьте адрес сервера, порт и
параметры подключения.
